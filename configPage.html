Top Songs settings

Shows an artist’s popular Last.fm tracks that are available in your Emby library.

Last.fm

Create a Last.fm API account and paste its API key below (not the shared secret). Public charts do not require a Last.fm login.

Display

How many matched songs the Top Songs list shows (1–50). On artist pages, click Top Songs > next to Songs > to open it.

Troubleshooting (optional)

If Top Songs is missing, run diagnostics and share the report with the artist name. Your API key is not included.

Nothing showing after installing? Press Ctrl+F5 once in each browser that had Emby open before (Cmd+Shift+R on a Mac).

Top Songs adds one marked block to Emby's dashboard-ui\index.html to load its script. Uninstalling Top Songs removes it.
